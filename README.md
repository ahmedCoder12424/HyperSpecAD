# Hyper-Spec Anomaly Detection Pipeline

This document outlines the workflow for preprocessing datasets, creating anomaly detection datasets, running Hyper-Spec experiments, evaluating baseline methods, and generating figures.

---

# 1. Mass Spectrometry Preprocessing

Scripts are located in:

```
anomaly_ms_preprocessing_scripts/
```

This stage converts non-LC-MS datasets into MGF-style files that can be processed by the Hyper-Spec pipeline.

## 1.1 `create_mgf_spectras_from_single_spectrum.py`

Converts pigment datasets stored as TXT files into MGF-style datasets.

Each input TXT file contains a single continuous spectrum with two columns:

- m/z
- intensity

The script samples each continuous spectrum to generate multiple spectra, producing an MGF-style file compatible with Hyper-Spec.

---

## 1.2 `create_mgf_from_tofs_sims.py`

Parses and preprocesses ToF-SIMS battery datasets into MGF files suitable for Hyper-Spec.

---

## 1.3 `create_anomaly_files.py`

Creates anomaly datasets at multiple anomaly percentages.

Before running:

- Update the input and output paths.
- It is recommended to store the generated files under:

```
/hdd/data/
```

to reduce storage usage on the main filesystem.

The anomaly percentage range can be adjusted directly in the script.

---

# 2. Dataset Creation

Scripts are located in:

```
anomaly_dataset_creation_scripts/
```

## 2.1 Initial Clustering

Run:

```bash
./anomaly_dataset_creation_scripts/cluster_anomalies.sh
```

Before running:

- Set the path to the normal (non-anomalous) dataset.
- Set the path to the anomaly dataset.
- Choose an output directory (preferably under `/hdd/data/`).

This script preprocesses the datasets and generates initial clustering results for each anomaly percentage.

---

## 2.2 Create Train/Test Datasets

Run:

```bash
python create_inorganic_datasets_var_anomaly_size.py
```

Configure:

- `INPUT_PATH` to the output generated by the previous step.
- Output directory (recommended: `/hdd/data/`).

This script:

- Creates train/test splits.
- Evenly distributes the normal spectra between the training and testing sets to avoid introducing unseen normal clusters during evaluation.
- Inserts anomalies into the test set.
- Outputs the anomaly spectra into separate files for evaluation.

---

## Optional: Cluster Separation Analysis

To evaluate how well anomaly clusters are separated from normal clusters, run the separation analysis.

Scripts are located in:

```
anomaly_sep_anly_scripts/
```

Example:

```bash
python3 compute_cluster_separation.py \
    --cluster-results data/proteomics/cluster_results_main.csv \
    --metadata data/proteomics/1468_dataset_meta.csv \
    --spectra-hvs data/proteomics/spectra_hvs.npy \
    --outdir results/proteomics \
    --prefix proteomics_
```

The script reports statistics describing the separation between anomaly and normal clusters.

---

# 3. Hyper-Spec Anomaly Detection Experiments

Scripts are located in:

```
anomaly_expirement_scripts/
```

## 3.1 Run Parameterized Experiments

Run:

```bash
./anomaly_expirement_scripts/run_anomaly_detection_expirements_param.sh
```

Before running, update:

- Paths to the raw normal dataset.
- Paths to the anomaly dataset.
- Paths to the processed datasets.
- Output directories.
- Timing and accuracy result files.

Additional run directories can be added if multiple datasets or experiments are being evaluated.

### Tunable Parameters

The primary Hyper-Spec parameters include:

- `mz_interval` – Controls the bucket width.
- `anomaly_eps_percentile` – Controls the anomaly detection threshold.

These parameters determine the tradeoff between runtime and detection accuracy.

---

## 3.2 m/z Bucket Width Tradeoff Sweep

Run:

```bash
./anomaly_expirement_scripts/sweep_anomaly_mz_tradeoff_expirements.sh
```

This script evaluates multiple bucket widths (`mz_interval`) and records both runtime and detection accuracy for later visualization.

---

# 4. Baseline Methods

Run:

```bash
./baselines_param.sh
```

Update the input and output paths before execution.

This script evaluates the baseline anomaly detection methods using the same datasets generated for Hyper-Spec.

---

# 5. Generating Graphs and Figures

Scripts are located in:

```
anomaly_result_scripts/
```

## 5.1 Generate Performance Figures

Example:

```bash
python3 generate_plots_with_tables.py \
    --baselines=../baseline_results/Gr_HC_Si_trunc_organic_anom_baseline_summary.txt \
    --timing=../anomaly_validation_results/best_acc_organic_timing.txt \
    --accuracy=../anomaly_validation_results/best_acc_organic_acc.txt \
    --outdir=../tables/organic_best_acc
```

Before running, configure:

- Hyper-Spec timing results.
- Hyper-Spec accuracy results.
- Baseline summary results.
- Output directory.

The script generates:

- Timing comparison plots
- Precision plots
- Recall plots
- F1 score plots
- Additional evaluation metrics
- Publication-ready tables

---

## 5.2 Generate Runtime vs. Accuracy Tradeoff Plots

Example:

```bash
python3 plot_tradeoff.py \
    --acc-file results/proteomics/accuracy_raw.txt \
    --time-file results/proteomics/timing_raw.txt \
    --outdir plots/proteomics \
    --prefix proteomics_
```

This script visualizes the tradeoff between bucket width (`mz_interval`), runtime, and anomaly detection performance, allowing selection of an operating point based on either accuracy or throughput requirements.
